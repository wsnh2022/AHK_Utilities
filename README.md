# AHK Utilities

> A collection of AutoHotkey v2 scripts and tools. Each module solves one specific problem. Copy, configure, and run.

---

## Modules

| Folder | Script | What it does |
|---|---|---|
| [`csv-prompt-menu/`](csv-prompt-menu/) | `CsvPromptMenu.ahk` | Hierarchical AI prompt menu built from a CSV file — `Ctrl+Alt+P` |
| [`exe-version-launcher/`](exe-version-launcher/) | `ExeVersionLauncher.ahk` | Auto-launches the highest versioned `.exe` in a folder |
| [`gitsync/`](gitsync/) | `gitsync.bat` | One-click Git sync: fetch, pull, commit, push with logging |
| [`git-terminal-snippets/`](git-terminal-snippets/) | `GitTerminalSnippets.ahk` | GUI menu that pastes common Git commands into the terminal — `Ctrl+Shift+N` |
| [`learning/`](learning/) | `FunctionsVsMethods.ahk` | Reference script comparing AHK v2 standalone functions vs class methods |
