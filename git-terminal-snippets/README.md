# Git Terminal Snippets

An AHK v2 GUI that pastes common Git commands into the terminal.

**Hotkey:** `Ctrl+Shift+N`

## What it does

Opens a menu of pre-built Git commands for setting up a new GitHub repo:

1. Init local repo
2. Add remote origin
3. Pull remote main
4. Stage, commit, and push
5. Untrack a file from remote

Click any item to paste the command into your active terminal window.

## Requirements

- AutoHotkey v2.0+
- A terminal window focused when triggering the hotkey
